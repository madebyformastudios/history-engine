# Image prompts: The Mongol Empire in 5 Minutes

Tool: Google Flow, Nano Banana Pro. Aspect ratio 16:9 (012 may be 1:1).
Every prompt starts with its number so the downloaded file can be traced back to the runbook.
Tip: generate 001 first and use it as style reference for the rest. Use 009 (adult Genghis Khan) as an extra character reference when you generate 010, so he looks the same.
